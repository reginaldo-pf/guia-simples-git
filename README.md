# Guia de Contribuição

1. Faça fork deste repositório.
2. Clone seu fork e configure o repositório original como `upstream`.
3. Atualize sua `main` antes de começar (`git fetch upstream && git merge --ff-only upstream/main`).
4. Crie um branch descritivo: `feat/minha-melhoria` ou `fix/ajuste-css`.
5. Faça commits pequenos com mensagens claras.
6. Faça push para seu fork e abra um Pull Request para `main`.
7. Aguarde revisão e ajuste o que for solicitado. Após o merge, sincronize seu fork.
## Como contribuir
Veja o arquivo [CONTRIBUTING.md](./CONTRIBUTING.md) para o passo a passo (fork, branch, PR).
